# Wannie's Music Archive 🩵

A music player for Wendy's covers, live performances and songs that aren't (or are no longer) available on music streaming services.

- Player: https://taek0321.github.io/wannieplayer/
- Alternative link: https://wannie.taek.stream

## Files

- `index.html`: the player
- `songs.js`: the song list
- `translations.js`: Korean and Chinese names
- `sw.js`: lets the player open like an app and work offline
- `check.html`: checks that every song plays
- `fonts/`: the font used by the player

Songs are stored on Cloudflare R2 (wannie-music.taek.stream).
